# Planificación Feature — Instalador Discord Helper

Esta carpeta contiene la planificación del desarrollo del instalador y transformación del proyecto Discord-Helper hacia una aplicación instalable tipo Ollama.

## Objetivo general

Transformar el proyecto desde un script Python ejecutado manualmente hacia:

- Aplicación instalable
- CLI multiplataforma
- Servicio local persistente
- Instalador automático
- Configuración desacoplada del repositorio
- Soporte Linux y macOS

## Duración estimada

- Sprint 1 → Base instalable y CLI
- Sprint 2 → Servicios y configuración persistente
- Sprint 3 → Instalador automático y experiencia usuario

Duración estimada:
- 2 semanas por sprint
- Total estimado: 6 semanas
